# Student API

A simple REST API for managing student information using Node.js and Express.js.

## Features

- Add student details
- View student details
- Update student information
- Delete student records
- REST API based backend
- Easy to test using Postman

## Technologies Used

- Node.js
- Express.js
- JavaScript
- REST API
- Postman
